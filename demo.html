CommandCuts v1.0

Keyboard Shortcuts,
Reimagined

A glassmorphic command palette you can drop into any website. Define admin shortcuts, let users create their own, and never clash with OS or browser hotkeys.

🎨

Glassmorphic Design

Frosted glass, blur effects, and smooth animations. Dark and light themes built-in with full CSS variable customization.

⚡

Zero Dependencies

Pure vanilla JavaScript, under 25 KB. Works with React, Vue, Angular, or plain HTML. Just add one script tag.

🛡️

Conflict Detection

Automatically warns when shortcuts conflict with OS or browser reserved keys. 80+ reserved combos tracked.

🔒

Admin + User Shortcuts

Site admins lock essential shortcuts. End-users can add, edit, and remove their own — persisted in localStorage.

🔍

Smart Search

Real-time search across shortcut names, descriptions, key combos, and categories. Instant results as you type.

🌐

Cross-Platform

Auto-detects Windows, macOS, and Linux. Shows ⌘ vs Ctrl appropriately. Works in Chrome, Firefox, Edge, Safari.
